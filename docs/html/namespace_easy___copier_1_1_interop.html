enum Easy_Copier.Interop.FILEOP_FLAGS : uint

Flags that control file operations performed by IFileOperation.

Enumerator
FOF_MULTIDESTFILES 

Assigns multiple destination files for each source file.

FOF_CONFIRMMOUSE 

Not used.

FOF_SILENT 

Does not display a progress dialog box.

FOF_RENAMEONCOLLISION 

Gives the item being operated on a new name in collision operations.

FOF_NOCONFIRMATION 

Responds with 'Yes to All' for any dialog box presented.

FOF_WANTMAPPINGHANDLE 

Preserves undo information if possible.

FOF_ALLOWUNDO 

Preserves undo information, if possible.

FOF_FILESONLY 

Performs the operation on files only if a wildcard file name is specified.

FOF_SIMPLEPROGRESS 

Displays a progress dialog box but does not show file names.

FOF_NOCONFIRMMKDIR 

Does not confirm creation of a new directory if the operation requires one to be created.

FOF_NOERRORUI 

Does not display a user interface if an error occurs.

FOF_NOCOPYSECURITYATTRIBS 

Does not copy security attributes of the file.

FOF_NORECURSION 

Only operates in the local directory. Does not operate recursively into subdirectories.

FOF_NO_CONNECTED_ELEMENTS 

Does not move connected items as a group.

FOF_WANTNUKEWARNING 

Warns if an item is being permanently destroyed during delete.

FOF_NORECURSEREPARSE 

Does not traverse reparse points.

FOFX_NOSKIPWARNINGS 

Does not skip warnings.

FOFX_PREFERHARDLINK 

Prefers creation of a hard link over copying.

FOFX_SHOWELEVATIONPROMPT 

Shows elevation prompt if required.

FOFX_RECYCLEONDELETE 

Recycles items on delete if possible.

FOFX_EARLYFAILURE 

Fails immediately if any single operation fails.

FOFX_PRESERVEFILEEXTENSIONS 

Preserves file extensions during rename operations.

FOFX_KEEPNEWERFILE 

Keeps the newer file during collisions.

FOFX_NOCOPYHOOKS 

Does not execute copy hooks.

FOFX_NOMINIMIZEBOX 

Does not display a minimize box on progress dialogs.

FOFX_MOVEACLSACROSSVOLUMES 

Moves access control lists across volumes.

FOFX_DONTDISPLAYSOURCEPATH 

Does not display source path in progress UI.

FOFX_DONTDISPLAYDESTPATH 

Does not display destination path in progress UI.

FOFX_REQUIREELEVATION 

Requires UAC elevation for the operation.

FOFX_ADDUNDORECORD 

Adds an undo record.

FOFX_COPYASDOWNLOAD 

Treats copy operation as a download.

FOFX_DONTDISPLAYLOCATIONS 

Does not display source or destination locations in progress UI.

◆ SIIGBF

enum Easy_Copier.Interop.SIIGBF

Flags that specify how the image should be generated for IShellItemImageFactory.

Enumerator
SIIGBF_RESIZETOFIT 

Shrink the bitmap as necessary to fit, preserving its aspect ratio.

SIIGBF_BIGGERSIZEOK 

Passed by callers if they want to stretch the returned image themselves. For example, if the caller passes an icon size of 80x80, a 96x96 thumbnail could be returned.

SIIGBF_MEMORYONLY 

Return the item only if it is already in memory. Do not access the disk even if the item is cached.

SIIGBF_ICONONLY 

Return only the icon, never the thumbnail.

SIIGBF_THUMBNAILONLY 

Return only the thumbnail, never the icon.

SIIGBF_INCACHEONLY 

Allows access to the disk, but only to retrieve a cached item.
